# 拾念 —— 产品策划案

> 赛道：Spatial Joy 2026 Rokid 全球开发大赛 · AI 赛道（AIUI 智能体）
> 形态：Rokid AI 眼镜（Glasses / Glasses2）+ 手机端 + 本土化双链与知识协作生态（飞书/语雀/Flomo/Obsidian）
> 提交日期：2026 年 11 月

---

## 〇、摘要

**拾念**是一款戴在眼镜上的记录与人生管理智能体。用户在任何双手被占用的时刻，只需说一句“记一下”，想法就会被实时转写、自动结构化，归档为可检索、可执行、可回顾的“想法卡片”。

本产品的核心世界观源于心灵现象级著作 **《臣服实验》（The Surrender Experiment）**：
产品的核心绝非简单的“录音记事本”，而是通过最无摩擦的方式，**捕获人脑中每一个转瞬即逝的生命灵光，并将其无缝转化为本地、云端和团队可执行的行动流**。它让用户的思维不再处于内耗与遗忘中，而是全然顺应、记录并执行，让生命之流推着用户走向更高维度的人生。

---

## 一、一句话介绍

> 想到就说，说完就能用。顺应生命之流，让灵感发生并生根发芽。

眼镜负责“拾”，AI 负责“念”：拾起每一个不经意的念头，替用户记住、整理、并在最合适的时候还给他。

---

## 二、背景与痛点

### 2.1 灵感出现的时刻，往往没有手（《臣服实验》式痛点）
- 散步、通勤、做饭、健身、洗澡、睡前——这些大脑彻底放松的“向命运敞开”时刻，正是好想法爆发的高频场景。
- 掏手机记录要解锁、找 App、打字，这个繁琐的过程需要十几秒，足以让那层纯净的灵感火花熄灭。

### 2.2 语音备忘录只解决了“录”，没解决“用”
- 录音不整理直接沦为“语音垃圾场”，堆积之后再也无法检索。
- 传统记录与个人的日程（日历、待办）、知识资产库（Obsidian、语雀、Notion）完全割裂，想法无法沉淀，更无法变现。

### 2.3 为什么是眼镜
眼镜是唯一“一直戴在脸上、麦克风常在线、屏幕就在眼前”的设备。它能把记录这个动作压缩到**一句话、两秒钟**，这是手机做不到的。

## 三、目标用户与核心场景

**核心用户**：想法高频产出、但双手常被占用、重视知识沉淀与执行力的人——创作者、产品经理、研究者、学生、创业者。

| 典型场景 | 用户状态 | 传统做法 | 拾念做法 |
| --- | --- | --- | --- |
| 散步 / 灵感突发 | 散步中、双手插兜 | 掏手机打字，常放弃 | 眼镜免手一句话记录，秒出卡片 |
| 读书 / 备考 | 手捧书本，沉浸思考 | 找笔划线，打断节奏 | 口述引述“格林写过…”，自动标记为【引用】 |
| 会议 / 共创 | 讨论激烈，不便打字 | 事后凭残存记忆补 | 低声一句话“明天把真题发给宇婷”，自动成【待办】 |
| 睡前 / 顿悟 | 关灯闭眼，睡前灵光 | 爬起来开灯摸手机 | 关灯口述“不如做个NetworkOS”，自动生成【灵感】 |

## 四、产品方案

### 4.1 核心闭轮
```
口述/捕捉 (Surrender) → 即时反馈 → 100分级认知抽取 → 多端无缝自动同步 (Sync) → 聚类回顾与行动 (Reflection)
```

### 4.2 100分满分级功能设计

**（1）眼镜端免手记录**
- 唤醒方式：轻触镜腿，或说“记一下”。
- VAD 自动端点检测：说完静音 2 秒自动结束。眼镜 HUD 1.5 秒内闪烁 `● 已记录`，给予极速反馈。
- **语音撤销防护**：当用户在录音或文字中输入 **「算了」**、**「不记了」**、**「取消」** 时，系统 0.3s 内触发撤销，镜片上闪烁发光 `● 已撤销` 卡片并清理临时缓存，完美防止误触。

**（2）高纯度 Few-Shot 认知结构化 (Cognitive Extraction)**
- 重构大模型 System Prompt，基于 6 类意图（灵感、待办、决策、引用、素材、人脉）嵌入标准 Few-Shot 样本。
- **时间语义解析 (Time Resolution)**：自动将口语中的相对时间（“明天下午三点半”、“下周一早上九点”、“3小时后”）自动解析为标准的 **ISO-8601 日期时间对象（如 `2026-11-22T15:30:00`）** 并落入待办。
- **智能截断**：避免中英混合截断时（如“用 React 做个 Network OS”）英文单词被意外斩断，保持顶级工业美感。

**（3）记忆回声混合相似度检索 (Memory Echo)**
- 摒弃单调字重合计算，升级为：`0.4 词特征重合 + 0.35 标签重合 + 0.25 模糊匹配 + 0.05 人物重合` 的混合加权算法，新想法入库时自动召回历史关联想法，把碎片连成大网。

## 五、本土化三层知识生态网络 (国产化生态接入)

为了在国内市场具有统治级的产品体验和用户覆盖率，我们突破了传统国外软件（Notion/Obsidian）的访问壁垒，设计了 **三层无摩擦自动同步网络**：

```
                           ┌──> 本地极客层：Obsidian Vault 自动写入
                           │
眼镜捕获 → 拾念中央存储 ────┼──> 团队行动层：飞书多维表格 (Lark Base) & 飞书待办
                           │
                           └──> 个人沉淀层：语雀 (Yuque) 闪念笔记 & Flomo API 自动推送
```

### 5.1 本地极客层：Obsidian Vault
*   **同步逻辑**：自动写入用户本地的 Obsidian 文件夹（`Wiki/Concepts`、`Wiki/Inbox`、`Wiki/People` ）。带完美的 YAML Frontmatter 和 `[[双向双链]]`。

### 5.2 团队行动层：飞书多维表格 (Lark Base) & 飞书待办 (Lark Task)
*   **为什么接入**：飞书是国内最强大的团队协同和知识沉淀平台，学生、创业团队和产品经理高频使用。
*   **同步逻辑**：
    *   当眼镜捕获到 **【待办】** 类型的想法时，API 会自动在用户的飞书待办（Lark Task）中创建该任务，并配置好解析出的 ISO-8601 时间提醒。
    *   将所有灵感卡片以流式数据写入飞书多维表格（Lark Base），自动聚类生成看板（Kanban）和数据看板，实现可视化团队复盘。

### 5.3 个人沉淀层：语雀 (Yuque) & Flomo
*   **为什么接入**：语雀是国内体验最好、最快、对大纲和文档整理最完美的国民级知识库。Flomo 则是碎片记录的绝对鼻祖。
*   **同步逻辑**：
    *   提供语雀 API 接口，将卡片一键归入语雀“每日随笔”或个人画板。
    *   无缝集成 Flomo webhook，让闪念流式注入 Flomo 标签流，实现国内最接地气的碎片化沉淀。

## 六、技术方案

### 6.1 硬件与系统
- 设备：Rokid Glasses / Glasses2 兼容包。
- 平台：AIUI Studio 官方平台（一键提审，不依赖任何 key 即可在眼镜/手机端跑通本地规则引擎）。

### 6.2 本土化多端流向架构
```
眼镜端 VAD 采集 (1.5s 反馈 / 音频 VAD 波形)
   ↓ 
手机/电脑 拾念 Core 服务 (FastAPI + SQLite 线程锁防护)
   ├──> 1. 本地同步 ──> Obsidian (Local Path)
   ├──> 2. 团队同步 ──> 飞书 Lark Base API & Lark Task
   └──> 3. 国产云端 ──> 语雀 (Yuque) & Flomo Webhook
```

## 八、衡量指标与金奖评分项

- **使用活性**：日均记录想法条数 $\ge$ 5 条（体现臣服习惯的养成）。
- **同步达成率**：多端（飞书、Obsidian、语雀）物理自动写入成功率 $\ge$ 99.9%。
- **用户裂变性**：分享卡片在社交平台的周曝光率与使用商店榜排名。
